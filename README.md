# Telegram Inline AI Bot

An inline Telegram bot that answers your questions directly in any chat via `@bot_username query`. Powered by DeepSeek V4 Flash Free.

## Features

- **Inline mode** — use `@bot_username` followed by your question in any Telegram chat
- **AI-powered answers** — backed by the DeepSeek V4 Flash Free model via OpenCode Zen API
- **User/group authorization** — restrict access to specific users or allow any member of specified groups
- **Long response pagination** — answers longer than ~3800 characters get a "Continue" button
- **Customizable identity** — bot name, username, and developer credit are all configurable
